WhatnotTrust & Safety · Internal Tools

Reduced repetitive investigation work with internal tooling.

Trust & Safety investigations involved repeated lookups, manual capture, tool switching, and recurring actions across similar case types. I built tooling around the actual workflow instead of asking the team to work around the software.

  • Built a Chrome extension to capture investigation data and reduce manual entry.
  • Combined recurring multi step actions into simpler workflows.
  • Used SQL and Snowflake to investigate user, livestream, and time window data.
  • Worked directly with the people using the tools and iterated around real case handling.
