04Creator WorkflowValoCut

Automating the boring first pass of video editing.

I was spending time repeatedly removing silence and dead space before the creative edit even started. ValoCut analyzes footage, finds useful speech, builds sensible cuts, and generates a timeline that imports into DaVinci Resolve.

  • Adaptive noise calibration and voice filtering instead of a single volume threshold.
  • Padding, nearby segment merging, micro segment rejection, and multiple processing profiles.
  • Parallel multi file processing with multi track audio support through FFmpeg.
  • Outputs FCP7 XML that can be imported directly into DaVinci Resolve.
