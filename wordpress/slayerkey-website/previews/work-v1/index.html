04Creator WorkflowValoCut

Automating the first editing pass.

I was spending time repeatedly cutting silence and dead space before the creative editing even started. ValoCut analyzes footage, detects usable speech, merges sensible segments, and generates a Resolve compatible edit timeline.

  • Adaptive noise calibration and voice band filtering instead of a single naive volume threshold.
  • Padding, nearby segment merging, micro segment rejection, and multiple processing profiles.
  • Parallel multi file processing with multi track audio support through FFmpeg.
  • Outputs FCP7 XML that can be imported directly into DaVinci Resolve.

How I work

The same loop keeps showing up.

01Find the friction

Look for the part people repeat, tolerate, misunderstand, or avoid.

02Understand the user

Figure out what actually matters in the workflow instead of building from assumptions.

03Build the system

Use the simplest useful combination of software, process, content, or automation.

04Ship and measure

Put it in front of real people, watch what happens, and improve from evidence.
